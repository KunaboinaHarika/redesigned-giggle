# AI Language Translation Tool 🌐

An intuitive web application built with Python and Streamlit that translates text across multiple global languages with Text-to-Speech (TTS) capabilities.

## 🚀 Key Features
- **Multi-Language Support**: Translates text across English, Spanish, French, German, Hindi, Japanese, Chinese, and Arabic.
- **Interactive UI**: Clean, user-friendly interface built with Streamlit.
- **Text-to-Speech (TTS)**: Plays translated output as audio using Google TTS.

## 🛠️ Tech Stack
- **Language**: Python 3.x
- **UI Framework**: Streamlit
- **Translation API**: `deep-translator`
- **Audio Output**: `gTTS`
